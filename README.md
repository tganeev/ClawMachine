# Claw Machine: Бионический тренажер

Мобильная игра-тренажер для обучения управлению бионическим протезом верхней конечности. Игрок управляет клешней автомата через два мышечных сигнала (сгибание и разгибание) в режиме ЭМГ или через поток событий СПППР, чтобы достать игрушки и выполнить миссии уровня.

## 📋 Требования

* **Unity Hub** и **Unity 2022.3 LTS** (или новее).
* **Android Build Support** (SDK, NDK, OpenJDK) — для сборки под Android. Устанавливается через Unity Hub -> Installs -> Add Modules.
* **Git** — для клонирования репозитория.

## 🚀 Запуск в редакторе Unity

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_репозитория>
   cd ClawMachine
   ```
2. Откройте проект:
   - Запустите Unity Hub.
   - Нажмите `Add` (Добавить) и выберите папку с проектом.
   - Откройте проект и дождитесь окончания импорта ассетов (может занять несколько минут).
3. Запустите игру:
   - В окне `Project` перейдите в папку `Assets/Scenes`.
   - Дважды кликните на сцену `MainGame`.
   - Нажмите кнопку **Play** (▶) в верхней части редактора.

## 📱 Сборка под Android (APK)

1. В Unity перейдите в меню **File -> Build Settings**.
2. В разделе `Platform` выберите **Android** и нажмите `Switch Platform`.
3. Нажмите **Player Settings**:
   - В разделе `Other Settings` установите **Package Name** (например, `com.hackathon.clawmachine`).
   - Установите **Minimum API Level**: Android 7.0 (API 24) или выше.
4. Вернитесь в **Build Settings** и нажмите **Build** (или `Build And Run`, если телефон подключен по USB).
5. Выберите папку для сохранения `.apk`. После сборки установите APK на телефон.

## 🎮 Инструкция по использованию

### Главное меню
- **Играть** — начать основной игровой процесс.
- **Обучение** — интерактивный туториал (рекомендуется для первого запуска).
- **Настройки** — выбор режима управления.
- **Выход** — закрыть игру.

### Режимы управления
В настройках можно выбрать один из трех способов:
1. **ЭМГ (Клавиши A/D)** — ползунки на экране имитируют сигналы мышц. Игрок тянет ползунок вверх (или зажимает клавишу), чтобы сжать клешню. Чем сильнее сигнал, тем крепче захват.
2. **СПППР (Клавиши W/S)** — управление имитирует поток жестов. Клешня реагирует на разницу между сгибанием (W) и разгибанием (S).
3. **Кнопки (Тач)** — классическое управление через экранные кнопки «Согнуть» и «Разжать».

### Цель игры и миссии
На каждом уровне вам нужно выполнить **3 миссии** (например, «Собери все игрушки», «Не используй 2-й канал», «Уложись в 50 секунд»).
- Игрушки, которые нужно достать, отображаются иконками в правой части табло.
- Когда вы подцепляете игрушку и несете её в отсек сброса, в левой части табло загораются зеленые галочки.
- Если вы нарушаете условия миссии (например, используете запрещенный канал), она закрашивается красным, и уровень придется перезапустить.
- Как только все миссии выполнены (закрашены зеленым), уровень пройден, и вы переходите на следующий.

## 🛠️ Технический стек
- **Движок:** Unity 2022.3 LTS (3D).
- **Язык:** C#.
- **Графика/Звук:** Процедурная генерация иконок и звуков (без использования внешних файлов, кроме фоновой музыки в `Assets/Resources`).
- **Целевые платформы:** Android (iOS поддерживается, но требуется Mac для сборки).

## 📂 Структура проекта
- `Assets/Scripts/` — все скрипты на C#:
  - `ClawController.cs` — управление клешней, физика и захват.
  - `MissionManager.cs` — логика миссий, таймер и условия перехода.
  - `LevelManager.cs` — управление уровнями и режимами.
  - `InputManager.cs` — коммутатор источников ввода (ЭМГ/СППР).
  - `SoundManager.cs` — генерация звуков и фоновой музыки.
  - `SceneBuilder.cs` — процедурная сборка UI и сцены.
- `Assets/Resources/` — префабы игрушек и фоновый трек.

## 📝 Примечания для жюри
- **Отсутствие реального протеза:** В рамках хакатона реальный протез не используется. В игре реализованы программные эмуляторы ЭМГ-сигналов и СПППР.
- **Интеграция:** Архитектура спроектирована так, чтобы эмуляторы можно было легко заменить на реальный драйвер протеза (через интерфейс `IControlInput`). Подробности в `TECHNICAL_DOCS.md`.
